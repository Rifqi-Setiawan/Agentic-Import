# Artha visual refresh

The user supplied five logistics-dashboard references. This implementation follows their light gray canvas, white rounded surfaces, emerald actions, compact company sidebar, status pills and modular dashboard layout, adapted to import compliance.

- Brand: Artha. Primary action #14b474; pale mint #d9f2e4; subtle neutral borders and dark text.
- Dashboard: live company-scoped shipment totals, readiness distribution, operational counts, attention queue and recent shipments. No fabricated history, growth trends, tracking locations or notification counters.
- Existing shipment, classification evidence, review, documents, duties, PIB and AI trace use the same light theme. Shipment search filters actual API results.
- Mobile: stacked cards, horizontal navigation, contained table overflow; reduced sidebar detail on short screens.
- Public application title and API title are Artha. Existing deployment URL, Git repository, internal service IDs, authentication storage and demo credentials remain compatible.
- Visual QA: desktop dashboard, 390px mobile viewport, shipment search, detail navigation and reviewer-accepted HS display checked in the browser. No data mutation required for visual testing.
